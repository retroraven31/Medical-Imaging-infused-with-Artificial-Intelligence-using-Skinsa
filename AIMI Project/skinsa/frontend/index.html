The Imbalance Challenge

The HAM10000 dataset exhibits extreme class imbalance. The Melanocytic Nevi (NV) class accounts for ~67% of all samples (6,705 images), while rare classes like Vascular Lesions (VASC) have only 142 samples — a 47:1 imbalance ratio.

Without correction, a naive model could achieve 67% accuracy by always predicting NV, while failing completely on the clinically important melanoma class.

The paper addresses this via class-weighted cross-entropy:

w_i = N / (C × N_i)
🔄
Experiment Protocols
📄 Paper Protocol (--protocol paper)
Stratified random 90/10 split at image level. Replicates the authors' evaluation exactly. Risk of data leakage if same lesion appears in both splits.
🔬 Lesion Protocol (--protocol lesion)
StratifiedGroupKFold(10) grouped by lesion_id. Creates 80/10/10 split. Guarantees zero lesion leakage. Test set evaluated with 8-view Dihedral TTA (identity + 3 rotations × horizontal flip). Same trained weights for fair comparison.
